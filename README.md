One sentence, at most 200 characters, explaining the modern internet to a
traveler arriving from the year 1800 — built only from things they already
know (libraries, post offices, markets, roads), with no word coined after
their time.

> Every library, post office, and market in the world is joined by one road, and whatever you send down it — a letter, a book, a song — arrives before your candle burns low.

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (override with
`MAKEFUN_OUTPUT_DIR`). Python standard library only, no network,
deterministic — every run produces byte-identical output.
